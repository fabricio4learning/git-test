// O QUE ELA FAZ

Simples por fora.
Especial no seu dia.

Tudo que você precisa para transformar alguns segundos no terminal em um momento de inspiração.

✳

Frase do dia

Uma frase motivacional escolhida de acordo com o dia do ano, para começar com uma nova perspectiva.

↻

Novas perspectivas

Atualize a frase a qualquer momento e descubra outra mensagem da sua coleção.

＋

Sua coleção

Adicione suas próprias frases e mantenha tudo salvo localmente em um arquivo JSON.

◷

Lembretes

Agende uma notificação do sistema para receber a frase do dia depois de alguns minutos.

⌨

Feita para o teclado

Navegue com as setas, selecione com Enter e feche com Esc. Sem tirar as mãos do teclado.

◇

Interface minimalista

Uma experiência TUI limpa e acolhedora, com cores suaves e foco no que importa.

// PRIMEIROS PASSOS

Inspiração em poucos comandos.

O projeto é feito em Node.js e funciona diretamente no terminal.

01.

Prepare o projeto

Instale as dependências usadas no código.

$ npm install blessed figlet node-notifier
02.

Execute a aplicação

Na pasta do arquivo principal, inicie a CLI.

$ node index.js
03.

Encontre sua frase

Navegue pelo menu, salve novas frases e programe lembretes.
